## Descripción
Práctica de Integración Continua (CI) con **GitHub Actions** que ejecuta un programa Hola Mundo en JavaScript y envía automáticamente una notificación a `ntfy.sh/devops-itla` cada vez que se realiza un `push` a la rama `main`.

## Estructura del Proyecto
* `index.js`: Programa Hola Mundo en JavaScript.
* `.github/workflows/alerta.yml`: Flujo de GitHub Actions para ejecución y notificación automática.
